# Online Book Store Management System

# Overview

A SQL-based mini project for managing and analyzing an online book store database. The project demonstrates practical SQL queries to extract useful business insights.

# Tools Used

* PostgreSQL
* SQL

# Key Analysis

* Customer and order analysis
* Book and author analysis
* Sales and revenue analysis
* Filtering and sorting data
* Aggregation and grouping
* Business insights using SQL queries

# SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* JOIN
* Aggregate Functions
* Subqueries

# Project File

* Mini_Project.sql — Contains the SQL queries used in the project.

#Objective

To practice SQL and database analysis skills by solving real-world business questions for an online bookstore.
